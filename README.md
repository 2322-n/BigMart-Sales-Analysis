# BigMart-Sales-Analysis

## Project Overview

BigMart Sales Analysis is an end-to-end data analytics project focused on analyzing retail sales data to identify sales trends, product performance, outlet performance, and key business insights.

The project uses **Python, Excel, SQL, and Power BI** to clean, analyze, visualize, and present the data.

## Objectives

* Analyze overall sales performance
* Identify top-performing product categories
* Analyze outlet performance
* Understand the impact of product attributes on sales
* Identify sales trends and patterns
* Create an interactive Power BI dashboard
* Generate actionable business insights

## Tools & Technologies

* **Python** – Data cleaning, preprocessing and exploratory data analysis
* **Pandas** – Data manipulation
* **Matplotlib, Seaborn** – Data visualization
* **Excel** – Data cleaning and preliminary analysis
* **SQL / MySQL** – Data querying and business analysis
* **Power BI** – Interactive dashboard and data visualization

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis
5. SQL Analysis
6. Dashboard Development
7. Business Insights

## Data Cleaning

The dataset was inspected for:

* Missing values
* Duplicate records
* Incorrect data types
* Inconsistent categorical values
* Outliers
* Data quality issues

The cleaned dataset was then used for further analysis and visualization.

## Key Analysis

The analysis covers:

* Total Sales
* Average Sales
* Product Performance
* Item Type Analysis
* Outlet Performance
* Outlet Location Analysis
* Outlet Size Analysis
* Fat Content Analysis
* Sales Distribution
* Top-performing products/categories

## Power BI Dashboard

The Power BI dashboard provides an interactive view of BigMart sales performance.

### Dashboard Features

* Total Sales KPI
* Average Sales KPI
* Total Items
* Outlet analysis
* Product category analysis
* Sales by outlet type
* Sales by location
* Sales by fat content
* Interactive slicers and filters

## Key Insights

The analysis helps identify:

* Which product categories contribute the most to sales
* Which outlets perform better
* How outlet characteristics affect sales
* Which product attributes are associated with higher sales
* Important patterns in overall retail performance
